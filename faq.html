Returns & Exchanges

We offer a 30-day return policy for unworn items in original condition with tags attached. Items must be in resellable condition. Customized items are not eligible for returns unless there's a defect. For full details, see our returns policy.

  1. Log into your account and go to "My Orders"
  2. Select the item you want to return
  3. Print the return label
  4. Package the item securely
  5. Drop off at any authorized carrier location
We'll process your refund within 5-7 business days after receiving the item.

Yes! We offer size exchanges for the same item. If you need a different size, simply return the original item and place a new order for the correct size. We'll process the refund for the returned item once we receive it.
